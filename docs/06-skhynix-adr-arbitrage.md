# 06 · SK하이닉스 ADR ↔ 본주 아비트라지 봇 계획

2026-07-10 나스닥 상장 예정인 SK하이닉스 미국 주식예탁증서(ADR)와 국내 상장
보통주(KRX 000660) 사이의 가격 괴리(프리미엄/디스카운트)를 추적·경보하고,
단계적으로 차익거래까지 연결하는 계획.

크립토 스택(문서 01~05)과 동일한 원칙을 적용한다:
**신호(프리미엄 감지) → 비용검증(올인비용 차감) → 실행(헷지 페어) → 리스크 가드**.
기존 알람봇들(`bn_hl_arbitrage` 등)의 패턴(폴링 → 스프레드 계산 → 임계값 → 텔레그램)을
그대로 재사용할 수 있어서 MVP는 며칠 안에 만들 수 있다.

---

## 0. 배경 요약 (2026-07-08 기사 기준)

- SK하이닉스 ADR이 7/10 나스닥 상장. 국내 보통주와의 **상호전환(펀저빌리티)** 이
  허용되는 방향으로 주관사단·한국예탁결제원이 운영규정을 조율 중.
- 단, **완전 자유전환이 아니라 심사·승인이 필요한 허가제**가 될 가능성이 높음
  → 전환 신청마다 절차와 시간이 걸림 → **괴리가 즉시 소멸하지 않고 밴드를 형성**한다.
- TSMC 사례: 전환이 제한적이면 ADR이 본주 대비 **구조적 프리미엄**을 장기간 유지
  (수급 분리). UBS는 이미 "ADR 매수 + 본주 매도" 전략을 제시.
- **시사점**: 전환이 느리고 비용이 드는 만큼, 괴리는 "즉시 사라지는 노이즈"가 아니라
  **측정·거래 가능한 시그널**이 된다. 이건 크립토의 김치프리미엄(A5 전략)과 구조가 같다.

## 1. 핵심 수식

```
parity_KRW  = ADR_USD × USDKRW ÷ ratio          # ADR을 본주 1주 기준 원화로 환산
premium_%   = (parity_KRW − KRX_KRW) / KRX_KRW × 100

# ratio = ADR 1주가 대표하는 본주 수 (예: 1 ADR = 0.5주면 ratio=0.5)
#   → 상장 확정 공시에서 확인 후 config로. 절대 하드코딩 추정 금지.

net_edge_% = |premium_%| − allInCost_%           # 이게 > 0일 때만 "진짜 엣지"
allInCost_% = 매매수수료(양측) + 세금 + FX스프레드 + 슬리피지
              (+ 전환 실행 시: ADR issuance/cancellation fee + 전환 소요일의 캐리비용)
```

크립토 플레이북의 공통 게이트 `net_bps = gross − allInCost − riskPremium > 0`
그대로다. 프리미엄 원값이 아니라 **비용 차감 후 순엣지로 알람**을 보내는 게 핵심.

## 2. 구조적 제약 — 크립토와 다른 점 (설계에 반영)

1. **거래시간이 전혀 겹치지 않는다.**
   KRX 09:00–15:30 KST vs 나스닥 정규장 22:30–05:00 KST(서머타임 기준).
   프리마켓(17:00 KST~)을 포함해도 KRX 장중과는 안 겹침.
   → 동시 체결 기반 HFT 차익은 **불가능**. 이 전략은
   "한쪽 장 종가/실시간가 대비 다른 쪽 장의 괴리에 베팅하고 다음 장에서 청산"하는
   **오버나이트 수렴 트레이드**다. 봇도 그 전제로 설계한다.
2. **FX 레그가 항상 낀다.** 프리미엄의 일부는 원/달러 변동일 수 있다.
   USDKRW 실시간(장외 24h) 소스가 필수이고, 프리미엄을 "FX 기여분 vs 순수 괴리분"으로
   분해해서 보여줘야 한다.
3. **국내 개인의 본주 공매도가 사실상 어렵다.**
   "ADR 롱 + 본주 숏" 정석 페어는 개인 계좌로는 대주 물량·요건 때문에 제한적.
   현실적 대안: (a) 이미 본주 보유 시 **본주 매도 ↔ ADR 매수 스위치**,
   (b) 숏 레그를 **KRX 개별주식선물(000660 선물)** 로 대체,
   (c) 전환 허가제 개시 후 **실물 전환 아비트라지**.
4. **세금 비대칭이 크다.** 국내 상장주식 매매차익은 소액주주 비과세인 반면
   ADR(해외주식)은 양도세 22%(기본공제 250만원). 배당 원천징수 경로도 다름.
   → 같은 1% 괴리라도 **어느 방향으로 잡느냐에 따라 세후 엣지가 다르다**.
   비용모델에 세후 기준을 반영한다.
5. **전환은 즉시가 아니다.** 허가제면 신청→승인→결제까지 며칠 소요 가능.
   그 기간의 가격변동을 헷지 못 하면 전환차익이 아니라 방향성 베팅이 된다.

## 3. 단계별 계획

### Phase 1 — 프리미엄 알람봇 (MVP, 상장일 전까지)

**목표**: 상장 첫날부터 ADR 프리미엄을 실시간 추적·기록·경보.
포지션 없이도 이 데이터 자체가 자산이다(밴드 통계가 Phase 2 임계값의 근거).

- **데이터 소스**
  - 본주: 한국투자증권(KIS) OpenAPI 실시간 시세 (무료, WebSocket). 백업: 네이버/야후 `000660.KS`(지연).
  - ADR: 상장 후 티커 확정 시 — IBKR API / Polygon.io / Finnhub / 야후(지연 15분).
    프리마켓·애프터마켓 시세 포함 소스 우선(괴리는 프리마켓에서 먼저 벌어진다).
  - USDKRW: 서울외국환중개 고시환율 + 실시간(예: 야후 `KRW=X`, 또는 IBKR IDEALPRO).
- **로직** (기존 `bn_hl_arbitrage` 골격 재사용)
  - 폴링 10~30s(정규장) / 60s(프리·애프터). 두 장이 다 닫힌 시간엔 슬립.
  - `premium_%` 계산 → FX 기여분 분해 → 비용 차감 후 `net_edge_%`.
  - 알람 조건(초기값, 데이터 쌓이면 재조정):
    - `|premium| ≥ 2%` 정보성 알람 (쿨다운 30분)
    - `net_edge ≥ 1%` 액션 알람 (쿨다운 10분, 방향·규모·근거 포함)
    - 프리미엄 **급변**(1h 내 ±1.5%p) 알람 — 뉴스/전환규정 발표 감지용
  - 상태 저장: SQLite (`hl_lighter_arbitrage` 패턴). 틱마다
    `ts, krx_price, adr_price, usdkrw, premium, net_edge, session(KRX/US/none)` 기록.
  - 알림: 텔레그램 (기존 봇 채널 재사용).
- **산출물**: 신규 레포 `adr_arbitrage_alarm` (Python, 기존 알람봇들과 동일 스택).
  Signal Bus(Phase 1, 문서 05)에 넣을 표준 신호 포맷도 처음부터 맞춰서 발행.

### Phase 2 — 밴드 분석 + 전략 신호 (상장 후 2~4주)

**목표**: "프리미엄이 몇 %면 진입할 가치가 있는가"를 데이터로 결정.

- 프리미엄 시계열에서 **평균/표준편차/반감기**(mean-reversion half-life) 추정.
  TSMC형(구조적 프리미엄 지속)인지, 수렴형인지 초기 데이터로 판별.
- 밴드 기반 신호: `z-score = (premium − rolling_mean) / rolling_std`,
  `|z| ≥ 2` && `net_edge > 0` 일 때만 진입 신호.
- 전환 허가제 세부규정 발표를 **이벤트 트리거**로 등록(규정 변화 = 밴드 레짐 변화).
- 부가 신호: KRX 장 마감 후 미국 반도체 섹터(SOX, 마이크론) 급변 시
  "내일 본주 갭 예상 vs 오늘 ADR 반영분" 괴리 알람 — ADR이 본주의 야간 프록시가 되므로.

### Phase 3 — 반자동/자동 실행 (밴드 검증 후)

정석 페어가 개인 계좌로 제한적이므로, 실행 경로를 3개로 나눠 순서대로 연결:

| 경로 | 구성 | 요건 | 리스크 |
|---|---|---|---|
| **3a. 보유물량 스위치** | 본주 보유 상태에서 ADR 프리미엄 고점 → 본주 매도 + ADR 매수 (또는 역방향 복귀) | KIS API + 해외주식 계좌(KIS or IBKR). 신규 자본 불필요 | 방향 노출은 유지되므로 델타 리스크 없음. 세금 비대칭만 주의 |
| **3b. 선물 헷지 페어** | ADR 롱 + KRX 000660 **개별주식선물 숏** (프리미엄 축소 베팅) | KIS 선물옵션 계좌, 선물 유동성 확인 | 만기 롤오버, 증거금, 야간 헷지 공백(선물도 주간만) |
| **3c. 실물 전환 아비트라지** | 본주 매수 → ADR로 전환 → 나스닥 매도 (또는 역) | **전환 허가제 절차 개시 후**. 예탁원/커스터디 신청 프로세스 자동화는 불가, 반자동 체크리스트로 | 전환 소요기간 중 가격변동 → 3b 선물로 기간 헷지 |

- 실행은 크립토와 동일하게 **paper → 소액 → 스케일** 3단계.
- Brain(문서 02) 관점에서는 이 전략도 하나의 신호 소스일 뿐 — `net_edge`와 자본요구량을
  표준 포맷으로 올리고, 자본배분은 Allocator가 결정.
- 킬스위치: 전환규정 변경 발표, USDKRW 일중 ±1.5% 이상, 본주 거래정지/공시 이벤트 시
  신규 진입 중지.

## 4. 비용 모델 (초기 추정 — Phase 1에서 실측으로 교체)

| 항목 | 추정 | 비고 |
|---|---|---|
| KRX 매도 세금 | 0.15% | 증권거래세+농특세 (코스피, 2026 기준 — 확인 필요) |
| KRX 위탁수수료 | 0.005~0.015% | 비대면 계좌 기준 |
| 미국 매매 수수료 | ~0 (IBKR $0.005/주 등) | SEC fee 미미 |
| FX 스프레드 | 0.02~0.1% | 증권사 환전 우대율에 따라. IBKR IDEALPRO면 최소화 |
| ADR 전환 수수료 | ADR당 ~$0.05 (TBD) | 3c 경로에만 해당 |
| 슬리피지 | 상장 초기 ADR 호가 얇으면 0.1%+ | slippage 레포 방법론(북 walk) 재사용 |
| **왕복 합계** | **대략 0.3~0.6%** | → 알람 임계 1%는 이 위에 안전마진 포함한 값 |

여기에 **세후 조정**(2절 4항)과 3c의 **전환기간 캐리**를 더해 최종 `net_edge` 산출.

## 5. 리스크 & 컴플라이언스 (문서 04 연장)

- **규제 리스크(최대)**: 펀저빌리티 세부규정이 아직 미확정. 허가제 조건·한도·방향 제한이
  전략 성립 자체를 좌우한다. → 규정 발표 전에는 Phase 1(모니터링)만. 실행 코드는 만들되 OFF.
- **외환 신고**: 전환·해외송금 규모가 커지면 외국환거래 신고 의무 검토. 개인 투자 규모에서는
  일반적으로 증권사 경유로 해결되지만, 3c를 키우기 전에 확인.
- **합법 범위**: 공개 시장가격 간 차익거래는 완전 합법. 다만 양 시장 동시 호가 조작성 주문,
  미공개정보 이용은 금지(기존 원칙 그대로).
- **모델 리스크**: ratio·세금·수수료 파라미터 오류가 가장 흔한 사고. 파라미터는 전부
  config + 단위테스트로 고정하고, 알람 메시지에 사용된 파라미터를 항상 병기한다.
- **유동성 리스크**: 상장 초기 ADR 스프레드/깊이 불안정. 첫 2주는 알람 임계값을 보수적으로.

## 7. 기존 스택과의 접점

| 기존 자산 | 재사용 방식 |
|---|---|
| `bn_hl_arbitrage` | 폴링→스프레드→breakeven→텔레그램 골격 그대로 |
| `hl_lighter_arbitrage` | SQLite 영속화 + 2차 신호(FX 분해) 패턴 |
| `slippage` | 올인비용(수수료+슬리피지) 프레임 → 주식 버전으로 이식 |
| `chiparbi` (A5 김치프리미엄) | "두 시장 + FX + 전환비용" 구조가 동일 — 프리미엄 분해 로직 공유 |
