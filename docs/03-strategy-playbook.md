# 03 · 전략 플레이북

기존 전략(이미 신호 보유) + 응용/신규 전략(수익원 확장). 각 전략은
`net_bps = gross − allInCost − funding − riskPremium > 0` 게이트를 공통으로 통과해야 한다.

전략은 두 묶음으로 본다: **A. 시장중립(델타 헷지, 본진)** / **B. 방향성·기회성(보조, 캡 작게)**.
"무자비하게"의 정답은 레버리지 도박이 아니라 **여러 중립 엣지를 동시에·고회전·복리로 굴리는 것**이다.

---

## A. 시장중립 전략 (본진)

### A1. 크로스-거래소 perp 스프레드 차익 (이미 보유: perpdex_arbitrage_alarm, autotrading_btc_eth)
- **엣지**: 같은 perp이 거래소마다 순간 가격 괴리. 싼 곳 롱 / 비싼 곳 숏 → 수렴 시 청산.
- **현황**: 5개 DEX 신호 + Cascade/RISEx 실행 엔진 이미 작동.
- **응용/확장**:
  - 신호(5 DEX)와 실행(2 DEX)을 **연결** — 지금은 단절. Signal Bus → Brain → Executor.
  - 거래쌍 확대: 신호가 보는 모든 (venue, pair) 조합으로 실행 leg 확장.
  - 임계값을 *알람용 0.2~0.3%* 가 아니라 *cost oracle 차감 후 net_bps* 로 재정의(거래소별 0~5.5bps 수수료 반영).
  - 동시체결 실패(half-fill) 자동 평탄화 강화.

### A2. 펀딩 캐리 (이미 보유: fundingrate_auto)
- **엣지**: perp 펀딩비를 받는 쪽으로 델타중립 포지션 → 가격무관 펀딩 수취.
- **현황**: 9개 거래소 펀딩 8h 정규화 + 배분 최적화가 스프레드시트로만 출력.
- **응용/확장**:
  - 최적화 결과를 **자동 실행**으로 연결(현재 수동 리밸런싱).
  - 제약 그대로 코드화: OI 캡 deposit×5, Binance 2× 한도, SOL/BNB 0.8× 댐핑, Variational $3M 최소.
  - **A1과 결합**: 베이시스 차익 진입 시 펀딩 부호를 골라 *스프레드 + 펀딩* 동시 수취(bn_hl의 breakeven_hours 로직 활용 — 펀딩이 우호적이면 수렴 안 돼도 보유 수익).
  - 펀딩 플립 예측: 펀딩 추세로 8h 전 선제 포지셔닝.

### A3. 현물-선물 베이시스 / 캐시앤캐리 (신규 응용)
- **엣지**: 현물 롱 + perp 숏(또는 역) → 베이시스 수렴 + 펀딩 수취. 변동성에 거의 무관.
- **레버리지**: bn_hl/hl_lighter의 베이시스 계산 로직을 현물↔perp로 확장. slippage 오라클로 양 leg 비용 검증.
- **대상**: BTC/ETH/SOL/BNB (유동성 충분, 펀딩 데이터 이미 수집 중).

### A4. mark/index 괴리 평균회귀 (이미 보유: hl_lighter_arbitrage의 2차 신호)
- **엣지**: perp mark가 index에서 벌어지면 회귀에 베팅(펀딩이 회귀를 강제).
- **현황**: trade.xyz mark/index gap 신호 보유.
- **응용**: gap > 임계 시 mark 반대로 진입, index 수렴 시 청산. A2 펀딩과 자연 결합.

### A5. 김치 프리미엄 / CEX×DEX 차익 (이미 보유: chiparbi)
- **엣지**: 한국 거래소(Upbit/Bithumb KRW) vs 글로벌 CEX/DEX 가격차 − 브리지·환전 비용.
- **현황**: 모니터 전용, 실행 명시적 배제. CHIP/OFT 토큰 대상.
- **응용/확장 (주의 필요)**:
  - chiparbi의 LayerZero OFT 헬퍼(`buildSendParam`)·Across 견적·BFS 라우팅을 실행 leg로 승격.
  - **선결 조건(코드에 이미 경고됨)**: 토큰 브리지 가능성 확인, 입금 네트워크 확정, KRW 출금/송금 한도·실명계좌 규제 확인.
  - net = gross spread − 브리지비 − CEX수수료 − 슬리피지 − 환전스프레드 를 *단일 수치*로 계산(현재 분리 표시).
  - ⚠️ 한국 외환/자금세탁방지 규제 영향이 큰 영역. 실거래 전 법률 검토 필수(문서 04 참고).

## B. 방향성·기회성 전략 (보조, 작은 캡)

### B1. 마켓메이킹 / 패시브 스프레드 수취 (신규)
- **엣지**: 유동성 얇은 perp DEX에서 양방향 지정가 → bid-ask 스프레드 + 메이커 리베이트. 다수 거래소가 메이커 수수료 0 또는 음수.
- **레버리지**: slippage 오라클이 이미 거래소별 북 깊이/스프레드를 안다 → 얇고 스프레드 넓은 시장 자동 선별.
- **리스크**: 인벤토리 편향 → A1/A2로 즉시 델타 헷지. 재고 한도 엄격.

### B2. 신규 상장 / 저유동성 토큰 차익 (신규, chiparbi 연장)
- **엣지**: 신규 상장·OFT 토큰은 거래소간 가격 정렬이 느림 → 큰 일시적 스프레드.
- **레버리지**: chiparbi의 멀티체인 가격 수집 + 상장시각 스케줄러(22:00 KST 패턴) 재사용.
- **리스크 캡 작게**: 유동성·러그·브리지 리스크 큼. AI 게이트(3c)로 사기/디페그 사전 차단.

### B3. 청산 캐스케이드 대응 (신규, 합법 범위)
- **엣지**: 대규모 청산으로 perp 가격이 일시 과이탈 → 평균회귀 진입. (남의 주문을 *유발*하지 않음 — 시장조작 아님. 이미 발생한 디슬로케이션에 *반응*만.)
- **레버리지**: perpdex_assets가 이미 청산가를 추적 → 청산 밀집 구간 매핑 가능.

## 전략 우선순위 (구축 순서)

| 우선 | 전략 | 이유 |
|---|---|---|
| 1 | A1 크로스-거래소 perp 스프레드 | 신호+실행 둘 다 이미 있음. 연결만 하면 됨. 최단경로. |
| 2 | A2 펀딩 캐리 | 최적화 로직 완성. 가장 안정적·예측가능한 수익. |
| 3 | A4 mark/index + A3 베이시스 | A1/A2 인프라 재사용. 추가 엣지. |
| 4 | B1 마켓메이킹 | 회전율↑ 복리 가속. 헷지 인프라 필요(A 완성 후). |
| 5 | A5 김치/CEX×DEX | 수익 크지만 규제·운영 복잡. 법률검토 후. |
| 6 | B2/B3 기회성 | 작은 캡, AI 게이트 의존. 마지막. |

## 공통 실행 규칙

1. **모든 진입은 cost oracle 통과 후 net_bps > min_edge.** 예외 없음.
2. **델타중립 우선.** 방향성(B2/B3)은 전체 자본의 소액 캡.
3. **고회전 + 복리.** 작은 엣지(수십 bps)를 하루 수백 회. 수익은 OI 캡 내 재투자.
4. **상관 관리.** 여러 전략이 같은 BTC 델타를 만들지 않게 Allocator가 순노출 합산.
5. **페이퍼 → 소액 라이브 → 스케일.** 신규 전략은 반드시 이 단계.
